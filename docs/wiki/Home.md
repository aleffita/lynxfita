# Welcome to the LynxFita Research Wiki

LynxFita is a next-generation high-performance desktop and embedded runtime for LynxJS applications, replacing legacy JSON IPC bridges and Node.js overhead with **Static Hermes AOT**, **C++20 JSI direct bindings**, **Cell Broadband Engine (CBE) Element Interconnect Bus (EIB) stationary memory & DMA lanes**, and **CORDIS spatiotemporal composability**.
