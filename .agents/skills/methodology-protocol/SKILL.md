# Methodology Protocol & Epistemic Feedback Governance

## When to Use
Use when:
- Receiving unstructured, high-density feedback or vision dumps from the principal.
- Ingesting architectural shifts, new technical paradigms (e.g., EIB DMA, CORDIS composability, zero-GIL multithreading).
- Coordinating multi-agent swarms with strict democratic centralism (centrality of decision in the principal, unity of action across worker agents).

## Operational Directives

### 1. Anti-Premature Ingestion Directive
- **NEVER** construct a task list linearly while reading the initial sentences of a prompt.
- The principal is neurodivergent (Twice-Exceptional / 2e: High Abilities / Giftedness + ADHD + Autism) and thinks topologically and non-linearly.
- Complete reading the entire prompt verbatim, cross-examine with existing code and scientific literature, and synthesize dialectically before committing to execution steps.

### 2. Systematic Epistemic Review Protocol
1. **Verbatim Preservation**: Persist the raw feedback dump into `docs/transcripts/YYYY-MM-DD-*.md`.
2. **Decoupage & Extraction**: Extract technical requirements, domain constraints, negative invariants (what NOT to do), and conceptual paradigms.
3. **Ontological & Glossary Sync**: Update `docs/glossary.md` and `AGENTS.md` with newly introduced terms and models.
4. **Subagent Specialization**: Assign specialized roles (Runtime Specialist, Desktop Architect, Protocol Governor, Docs Curator) without overlapping scopes.
5. **Atomic Execution & Material Verification**: Execute single atomic steps sequentially, passing the baton step-by-step and verifying each intermediate milestone with real physical tests.
6. **Pre-Commit Empirical Reality Check**: Verify that every documented feature or benchmark corresponds to real, executable native code. Strictly prohibit toy stubs, simulated VMs, or synthetic mock metrics.

## Subagent Orchestration Matrix
- **Lead Coordinator**: Maintains global strategic alignment, monitors CI/CD regressions, and communicates directly with the principal.
- **Runtime Specialist**: Manages C++20 JSI adapter, static Hermes AOT, stationary DMA ring buffers, and Protobuf bridge.
- **Desktop Architect**: Governs Win32 / Lynxtron / POSIX host environments, native modules, and packaging.
- **Protocol Governor**: Ensures anti-reward-hacking compliance, epistemic integrity, and Gitflow standards.
- **Docs Curator**: Maintains OKF compliance, living glossary, and public documentation retention.
